Here's my plan for a 5-hour build.

## Stack — I agree with you, with one addition

| Layer | Choice | Why |
|---|---|---|
| App | Next.js 15 App Router + TypeScript | Server components mean product/search pages need no client fetching layer; one repo, one deploy |
| Styling | Tailwind v4 + a few Radix primitives (dropdown, dialog, popover) | Amazon's header is flyout-heavy; hand-rolling those eats an hour |
| DB + Auth | Supabase (Postgres + Auth, email/password) | As you said. Auth is the part that saves the most time |
| Deploy | Vercel | As you said |
| AI | One Anthropic API call for the shopping assistant | The single cheapest "better than the original" feature |

**Do not use Stripe.** A fake card form that validates and "charges" is indistinguishable in a 5-minute walkthrough and saves 45 minutes of webhook plumbing.

## The spine — build in this order

This is the shopper's path end-to-end. Nothing gets built that isn't on it until it's all working.

1. **Global chrome** — header (hamburger nav, location picker, search with department dropdown, account flyout, live cart count), department subnav, footer. Amazon's IA *is* the product; getting this right sells the whole thing.
2. **Home** — hero carousel, category card grid, "Keep shopping for" rail, deals rail.
3. **Search + results** — query + department scope, faceted sidebar (department, price bracket, avg rating, brand, Prime), sort dropdown, result cards with rating stars and delivery date.
4. **Product detail** — image gallery with hover-zoom, variant swatches, price block with list-price strikethrough and % off, the buy box (delivery estimate, stock, qty, Add to Cart / Buy Now), description bullets, reviews with a rating histogram.
5. **Cart** — qty change, delete, save-for-later, subtotal, "your order qualifies for free delivery".
6. **Auth** — sign up / sign in, plus a **one-click demo login**. Judges will not create an account; if signing in is friction, checkout never gets seen.
7. **Checkout** — address → delivery speed → payment → review → place order. One page, three collapsible sections, exactly like Amazon's.
8. **Orders** — order history, order detail, a tracking status strip.

## What I'd cut, deliberately

Third-party sellers and seller dashboards, real payments, returns/refunds, Prime Video/Music/Photos, subscriptions and Subscribe & Save, wishlists/registries, Q&A on products, review submission, image upload, admin CMS, multi-address books beyond one address, coupons. Every one of these is visible on amazon.com and none of them is on the path from "land" to "I bought something."

## The two things that beat the original

1. **AI shopping assistant** — a search box that takes *"a gift for my dad who grills, under $50"* and returns real matches with a one-line reason each. Amazon genuinely cannot do this well. ~30 minutes.
2. **Restraint.** Amazon's UI is cluttered with ad slots, inconsistent type scale, and 1990s density. A clean, fast, consistent version of the same IA reads as "better" within three seconds of the walkthrough. This costs nothing extra if the design system is set up in the first 20 minutes.
